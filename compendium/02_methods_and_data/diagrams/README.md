# Research diagrams

These diagrams document the systems and methods developed for the project.
They are supporting materials for the research method and should be read
alongside [`../README.md`](../README.md).

| Diagram | Purpose |
|---|---|
| `Pipeline_Architecture_Diagram.png` | Shows how problem data, route planning, catch scenarios, stochastic evaluation, and experiment outputs connect. |
| `Project_Structure_Diagram.png` | Shows the repository components and their relationships. |
| `Recourse_Policies_Diagram.png` | Shows the actions taken after an overflow under the tested recourse policies. |

These are software/system schematics rather than physical engineering
drawings. No physical components or CAD files were used in this project.
