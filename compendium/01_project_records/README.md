# Project records

This folder contains the project's decision log and meeting minutes, together
with the action and contribution records.

## Files

- [`action_log.csv`](action_log.csv): actions and follow-up work.
- [`decision_log.md`](decision_log.md): decisions that affect methods or
  reproducibility.
- [`contribution_record.md`](contribution_record.md): project contributions.
- `meeting_minutes/`: add the meeting-minute PDFs here when available.
