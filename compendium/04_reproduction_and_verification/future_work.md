# Further development

Candidate future work identified during project discussions for the following:

## Route assessment

- improve reproducibility of wall-clock-limited heuristic solves;
- compare additional catch models and leave-one-year-out validation;
- develop overflow-aware route construction;
- compare route-repair methods under shared scenarios;
- improve route visualisation for many overflow events;

## Catch modelling

- develop hybrid or station-dependent models;
- implement catch models in routes and dynamic prediction;
- factor in trawl effort;
- develop alternative catch models;
- improve comparability between models via standardised tests.
